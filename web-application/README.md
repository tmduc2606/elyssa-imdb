## Quick Start

### Prerequisites

- Python 3.12+ with `web-application/api/.venv/` (or create one)
- Node.js 20+ with npm
- The 6 Gold Parquet marts at `data-science/marts/full/*.parquet` (generated by DE pipeline)
- DS artifacts at `data-science/marts/processed/` (generated by DS pipeline)
- (Optional) Redis on `localhost:6379` — falls back to in-memory cache

### Prerequisites Check

Before starting the API, verify upstream artifacts exist:

```powershell
if (-not (Test-Path "../data-science/marts/processed/feature_columns.json")) {
    Write-Error "DS artifacts missing — run data-science pipeline first"
    exit 1
}
if (-not (Test-Path "../data-science/marts/full/dim_title.parquet")) {
    Write-Error "Gold marts missing — run data-engineering pipeline first"
    exit 1
}
```

### Contract Conformance

```bash
pytest tests/test_contract.py -v    # verifies api-to-frontend.md compliance
```

### Backend

```bash
cd web-application/api
.venv\Scripts\activate     # Windows
# or: source .venv/bin/activate  # macOS/Linux
uvicorn app.main:app --reload --port 8000
```

The API serves at `http://localhost:8000`:
- GraphQL playground: `http://localhost:8000/graphql`
- REST docs: `http://localhost:8000/docs`
- Health check: `http://localhost:8000/health`

### Frontend

```bash
cd web-application/client
npm install
npm run dev                 # → http://localhost:5173
```

Vite proxies `/graphql`, `/auth`, and `/api` to the backend.

### Docker (full stack)

```bash
docker compose up -d        # starts api, redis, postgres, etc.
```

## API Endpoints

### GraphQL (primary)

| Query | Description |
|-------|-------------|
| `homepage` | Trending, top-rated, featured titles |
| `title(tconst)` | Full title detail with cast, crew, episodes, similar |
| `titleRatings(tconst)` | Rating timeline snapshots |
| `person(nconst)` | Person detail with filmography, known-for, collaborators |
| `search(query, first, after)` | Paginated title search (cursor-based) |
| `browse(genres, decade, ...)` | Paginated browse with filters |

### REST (`/api/v1`)

| Method | Path | Description |
|--------|------|-------------|
| GET | `/titles` | List titles (page, per_page, genre, year, sort) |
| GET | `/titles/{id}` | Title detail with principals |
| GET | `/titles/{id}/principals` | Cast & crew for a title |
| GET | `/persons/{id}` | Person detail |
| GET | `/persons/{id}/credits` | Person filmography |
| GET | `/search?q=&type=` | Full-text search (title/person/all) |
| POST | `/predict/genre` | Predict genres from features |
| POST | `/predict/rating` | Predict rating from features |
| GET | `/models` | List registered ML models |

### Auth (`/auth`)

| Method | Path | Description |
|--------|------|-------------|
| POST | `/register` | Create account (email, password, display_name) |
| POST | `/login` | Login → JWT access + httpOnly refresh cookie |
| POST | `/refresh` | Exchange refresh cookie for new access token |
| POST | `/logout` | Clear refresh cookie |
| GET | `/me` | Current user profile |
| GET | `/watchlist` | User's watchlist |
| POST | `/watchlist` | Add title to watchlist |
| DELETE | `/watchlist/{id}` | Remove from watchlist |

## Data Storage

### User Data (SQLite)

**Location**: `web-application/api/data/elyssa.db`

```
users     — id(UUID), email, display_name, password_hash(bcrypt), created_at
watchlist — id, user_id, tconst, title_json, added_at
```

Passwords are hashed with **bcrypt**. JWT access tokens expire in 15 minutes; refresh tokens stored in httpOnly cookies expire in 7 days.

### Analytics Data (DuckDB — in-memory)

6 Gold Parquet marts are loaded into DuckDB views at startup. Queries run in-process without a separate database server.

### Cache

Multi-tier: `Redis → TTL` with in-memory `dict` fallback. Configured via `ELYSSA_REDIS_ENABLED` env var (defaults to `true`).

| Model | Type | Task | Input Features |
